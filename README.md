This repository contains my hands-on practice and learning journey in SQL. It includes various SQL concepts that I have worked on and practiced step by step to strengthen my understanding of database querying and data manipulation.

## Topics Covered

I have practiced the following SQL concepts:

- 1 EMP_DEPT — Employee and department tables, basic database schema understanding, and data retrieval.
- 2 EXPRESSION_ALIAS — SQL expressions, arithmetic operations, and aliasing column names for better readability.
- 3 WHERE CLAUSE — Filtering records using conditions in SELECT statements.
- 4 LOGICAL OPERATOR — Using AND, OR, NOT and combining multiple conditions in queries.
- 5 SPECIAL OPERATOR — IN, BETWEEN, LIKE, IS NULL, and other special comparison operators.
- 6 MULTI ROW FUNTION — Aggregate functions such as SUM, AVG, COUNT, MIN, and MAX across multiple rows.
- 7 GROUP_BY CLAUSE — Grouping rows to summarize data based on one or more columns.
- 8 GROUP BY HAVING CLAUSE — Filtering grouped results using HAVING after aggregation.
- 9 SUB_QUERY_CASE_1 — Writing subqueries and practicing case-based SQL query logic.
